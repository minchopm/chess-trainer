Why AGPLv3

The app includes two engines. Stockfish is licensed under the GNU General Public License version 3. Reckless is licensed under the GNU Affero General Public License version 3. Both are copyleft: a work that includes either and is distributed must be distributed under the same terms.

Both are compiled into and linked with the application, so both obligations apply at once. Section 13 of the GPLv3 exists for exactly this case — it permits combining GPLv3 code with AGPLv3 code — and it says the Affero requirement governs the combined work. So the whole application carries AGPLv3. This is not a footnote we discovered late; it is the condition of using engines this strong, and it is a fair one.

The Affero clause is the difference between the two licences: it extends the obligation to publish source from distributing a program to letting people use it over a network. It changes nothing about how this app behaves. Both engines run on your device, the app makes no network requests, and there is no server of ours for anybody to interact with remotely. The source is published either way.

Two things follow, and both are worth knowing before you buy anything.

You get the source. Not a marketing gesture — a licence obligation, and your right. The repository holds the iOS app, the Swift rules engine, the training logic, the puzzle-mining pipeline and this website.

There will never be advertising in it. A proprietary advertising SDK compiled into the same binary would make the combined work undistributable under either licence. Selling the app is fine — copyleft has never forbidden charging — but bolting a closed SDK onto it is not.

The engine source is otherwise vendored unchanged. src/ffi.rs is a new file — a C interface over the engine, written for this project, and needed because the crate exports nothing usable: every module in src/lib.rs is private, so nothing outside it can reach the search. src/lib.rs gains one line declaring that module, and Cargo.toml gains staticlib to its crate types so it can be linked into an application. Lichess

Most of the bundled tactics puzzles come from the Lichess puzzle database, and the games behind Guess the Elo come from the Lichess game archives. Both are released into the public domain under CC0 1.0.

No attribution is required by that licence. It is given here because it is deserved: those 14,185 puzzles carry ratings calibrated against millions of real solving attempts, which is something no amount of local computation could produce.

Brass Pawn is not affiliated with or endorsed by Lichess. The bundled games keep the two players’ ratings and moves, and not their usernames.
